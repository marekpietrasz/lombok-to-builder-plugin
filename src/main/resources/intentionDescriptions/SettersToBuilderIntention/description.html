Folds a local variable declaration followed by setter calls into a single Lombok builder chain.

Example:

Foo f = new Foo();
f.setA(1);
f.setB("x");

becomes

Foo f = Foo.builder().a(1).b("x").build();

A setter whose value references the variable being built (e.g. a child pointing back at its parent) can't be folded into the builder. By default it is kept as a trailing setter after the builder; this is configurable under Settings | Tools | Lombok To Builder.

Only offered when the target class is annotated with @Builder or @SuperBuilder.
