Converts a constructor call of a Lombok @Builder class into the equivalent builder chain.

Example:

Foo f = new Foo(1, "x");

becomes

Foo f = Foo.builder().a(1).b("x").build();

Only offered when the target class is annotated with @Builder or @SuperBuilder.

By default, calls that resolve to a hand-written constructor are left alone, since such a constructor may run logic a builder would bypass. Enable Convert calls to hand-written constructors under Settings → Tools → Lombok To Builder to convert those too.
